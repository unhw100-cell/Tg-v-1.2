# План реализации RustGram: Нативный Rust-мост TDLib и интерфейс в стиле Telegram iOS

Полная доработка Android 16 приложения **RustGram** с устранением ошибки загрузки нативного JNI-моста, полноценной кросс-компиляцией Rust Core под Android NDK (`arm64-v8a` и `x86_64`) и переработкой UI/UX в стиле официального **Telegram для iPhone (iOS)** с полным набором мессенджер-функций.

---

### Подтверждённые решения пользователя

> [!IMPORTANT]
> Следующие решения подтверждены вами на этапе уточнения требований и определяют архитектуру и дизайн этого релиза:

- **Визуальный стиль**: Интерфейс в стиле **Telegram для iOS (iPhone)** — нижняя панель из 4 вкладок (*Контакты, Звонки, Чаты, Настройки*), центрированные заголовки навигации, скруглённые сгруппированные карточки настроек/профилей, встроенный поиск в стиле iOS, свайп-действия и плавные пружинные анимации.
- **Нативная интеграция Rust + TDLib**: Кросс-компиляция **Rust Core** через **Android NDK** в нативные библиотеки `.so` (`arm64-v8a`, `x86_64`, `armeabi-v7a`, `x86`), упаковка в APK и реализация сквозного JNI-моста между Kotlin, Rust и `libtdjson.so`.
- **Функциональный охват**: Исправление JNI для Android 16, экран переписки с обоями, свайпом для ответа и реакциями, запись/воспроизведение голосовых сообщений и медиа-пикер, профили пользователей/групп/каналов, создание групп и каналов, глобальный поиск.

---

### 1. Обзор и ключевая концепция

- **Назначение**: Альтернативный клиент Telegram для Android 16 (API 36), где бизнес-логика, парсинг сообщений, криптография, кэширование SQLite и взаимодействие с библиотекой TDLib выполняются на языке **Rust**, а слой **Jetpack Compose** отвечает за максимально точный, отзывчивый интерфейс в стиле **Telegram iOS**.
- **Проблема, которую решаем в первую очередь**: Ранее приложение падало при инициализации `TdClient` с ошибкой `No implementation found for int com.example.rustgram.NativeBridge.td_create_client_id()`, так как `libtdjson.so` экспортирует чистый C API, а не JNI-сигнатуры, а библиотека `librustgram_integration.so` не была скомпилирована под целевые Android ABI (`arm64-v8a`, `x86_64`).
- **Ключевая ценность**: После реализации Rust JNI-обёртка динамически связывается с `libtdjson.so`, устраняя сбой, а пользователь получает быстрый Telegram-клиент с эстетикой iOS, реальным подключением к TDLib, офлайн-кэшем в Rust SQLite и полным набором повседневных функций.

### 2. Пользовательский опыт и визуальный дизайн (Telegram iOS Aesthetic)

#### Ключевые сценарии использования
1. **Авторизация и настройка API**: Пользователь выбирает страну, вводит номер телефона (или сканирует QR-код), подтверждает код и 2FA-пароль. На экране входа доступна кнопка настройки собственных `API ID` и `API Hash` с пошаговой подсказкой `my.telegram.org/apps`.
2. **Навигация на главном экране (iOS Tab Bar)**:
   - Нижняя панель с четырьмя вкладками: **Контакты**, **Звонки**, **Чаты** (с живым счётчиком непрочитанных), **Настройки**.
   - Вверху экрана **Чаты**: центрированный заголовок `Чаты` (со статусом подключения *Соединение... / В сети*), слева кнопка `Изм.` (для массового выбора/закрепления/удаления), справа кнопка создания (новое сообщение, группа, канал).
   - Под заголовком: iOS-строка поиска и горизонтальная лента папок (*Все*, *Личные*, *Группы*, *Каналы*, *Боты*, *Непрочитанные*).
3. **Глобальный поиск**: Тап по строке поиска открывает мгновенный фильтр по недавним чатам, контактам, кэшированным сообщениям в Rust SQLite и публичным каналам/ботам через TDLib.
4. **Переписка и медиа**:
   - Фоновые обои чата (фирменный векторный узор Telegram + мягкий градиент, адаптирующийся под светлую/тёмную тему).
   - Свайп влево по любому сообщению с тактильной отдачей запускает **Ответ (Reply)**; короткое нажатие или удержание открывает iOS-меню действий с панелью быстрых реакций (👍 ❤️ 🔥 😂 👏 🎉) и пунктами *Ответить, Переслать, Закрепить, Копировать, Редактировать, Удалить*.
   - Нижняя панель ввода в стиле iOS: скруглённая капсула ввода текста, кнопка скрепки (запуск системного **Photo Picker** для фото, отправка файла, контакта или геопозиции) и переключаемая кнопка **Микрофон / Видеокружок** для реальной записи голосовых сообщений с живым расчётом амплитуд (waveform) в Rust.
5. **Профили, создание групп и каналов**:
   - Нажатие на заголовок чата открывает профиль собеседника, группы или канала со скруглёнными кнопками действий (*Звонок, Видео, Без звука, Поиск*), био/юзернеймом и вкладками *Медиа, Файлы, Ссылки, Участники*.
   - Из кнопки создания на вкладке *Чаты* доступен пошаговый экран создания новой группы или публичного/приватного канала.
6. **Настройки в стиле iOS**: Сгруппированные скруглённые секции с иконками в цветных квадратных бейджах (как в iOS Settings / Telegram iOS): *Учётная запись, API ID/Hash, Уведомления, Данные и память, Оформление (Светлая / Ночная тема), Язык и движок RustGram*.

#### Визуальная система и палитра
- **Светлая тема (Telegram iOS Light)**:
  - Фон списков/настроек: `#F2F2F7` (iOS Grouped Background) и `#FFFFFF` (чистые списки чатов).
  - Основной акцент: `#007AFF` (Telegram iOS Blue).
  - Пузыри сообщений: входящие `#FFFFFF` с деликатной тенью, исходящие `#E1FFC7` (или фирменный синий градиент `#34AADC` → `#007AFF` в стиле iOS, с переключателем стиля).
  - Вторичный текст и разделители: `#8E8E93` и `#C6C6C8` (тонкие 0.5dp линии).
- **Тёмная тема (Telegram iOS Dark)**:
  - Глубокий фон: `#000000` (OLED Black) и `#1C1C1E` (группированные карточки iOS).
  - Акцент: `#0A84FF`.
  - Пузыри: входящие `#1C1C1E` / `#262629`, исходящие `#2B5278` / `#0A84FF`.
- **Типографика**: Локально встроенные шрифты **Inter** (аккуратная геометрическая замена SF Pro для Android) и **JetBrains Mono** (для блоков кода и технических идентификаторов) с соблюдением масштабируемости `sp`.
- **Отступы и безопасные зоны**: Полный `enableEdgeToEdge()`, учёт `WindowInsets.navigationBars` на кастомной iOS-панели вкладок и `imePadding()` в поле ввода чата, минимальный размер кликабельных зон `48.dp`.

### 3. Ключевые технические решения и компромиссы

- **Решение 1: Сквозной JNI-мост в Rust (`dlopen` + прямая привязка к `libtdjson.so`)**
  - *Выбранный подход*: Вместо вызова голых `external fun td_*` напрямую из Kotlin к C-библиотеке `libtdjson.so`, все JNI-точки входа (`Java_com_example_rustgram_NativeBridge_*`) реализуются внутри Rust-модуля интеграции. Rust загружает символы `libtdjson.so` через `dlopen`/`dlsym` (с корректным fallback при отсутствии или ошибке) и проксирует запросы/ответы, одновременно пропуская их через модули Rust Core (парсинг Markdown, кэш SQLite, шифрование 2FA, нормализация вейвформ).
  - *Почему*: Гарантированно устраняет `UnsatisfiedLinkError` на Android 16 (`arm64-v8a` и `x86_64`), делает Rust реальным центральным звеном выполнения и предотвращает падение приложения на любом ABI.
  - *Альтернатива*: Написать тонкую C++-прослойку в Gradle CMake — отклонено, так как требование проекта — максимальное использование Rust как основного языка.

- **Решение 2: Кросс-компиляция Rust через Android NDK (API 36)**
  - *Выбранный подход*: Установка Android NDK через `sdkmanager`, добавление целей `aarch64-linux-android` и `x86_64-linux-android` в `rustup`, настройка линковщиков в Cargo и сборка `librustgram_integration.so` непосредственно в `jniLibs` перед сборкой APK.
  - *Почему*: Приложение запускается в потоковом эмуляторе (`x86_64`) и на реальных смартфонах Android 16 (`arm64-v8a`) с настоящим скомпилированным Rust-кодом.

- **Решение 3: Гибридный режим работы (Live TDLib + Rust SQLite Offline Cache)**
  - *Выбранный подход*: При наличии действительных `API ID`/`API Hash` и сети клиент отправляет реальные JSON-команды в TDLib (`setTdlibParameters`, `setAuthenticationPhoneNumber`, `getChats`, `sendMessage`, `searchPublicChats`) и принимает обновления в фоновом потоке. Все входящие/исходящие данные дублируются в локальной базе Rust (`rusqlite`), что обеспечивает мгновенное отображение интерфейса и корректную работу при отсутствии сети или на демо-входе.
  - *Почему*: Исключает пустые экраны до ввода пользовательских ключей Telegram и делает переключение чатов мгновенным.

- **Решение 4: Аудиозапись голосовых и выбор фото без широких разрешений**
  - *Выбранный подход*: Использование `ActivityResultContracts.PickVisualMedia` (Android Photo Picker без запроса `READ_MEDIA_IMAGES`) для отправки фотографий и `MediaRecorder` / `MediaPlayer` с runtime-запросом `RECORD_AUDIO` только в момент нажатия на запись голосового сообщения.
  - *Почему*: Полное соответствие политикам Google Play и Android 16.

### 4. Техническая архитектура и стратегия работы с данными

#### Диаграмма архитектуры системы

```
┌───────────────────────────────────────────────────────────────────────────┐
│                 Android 16 UI Layer (Jetpack Compose — iOS Style)         │
│  ┌──────────────┐ ┌──────────────┐ ┌───────────────┐ ┌─────────────────┐  │
│  │ Auth & API   │ │ iOS Tab Root │ │ Chat Detail   │ │ Profiles, Calls │  │
│  │ Setup Flow   │ │ (4 Tabs)     │ │ + Wallpaper   │ │ & Group Creator │  │
│  └──────┬───────┘ └──────┬───────┘ └───────┬───────┘ └────────┬────────┘  │
│         └────────────────┴─────────────────┴──────────────────┘           │
│                                    │ StateFlow / MVVM                     │
│                         ┌──────────▼──────────┐                           │
│                         │  TelegramRepository │                           │
│                         └──────────┬──────────┘                           │
└────────────────────────────────────┼──────────────────────────────────────┘
                                     │ JNI (NativeBridge)
┌────────────────────────────────────▼──────────────────────────────────────┐
│                  Rust Core Engine (librustgram_integration.so)            │
│  ┌───────────────┐ ┌───────────────┐ ┌───────────────┐ ┌───────────────┐  │
│  │ TDLib FFI     │ │ Messaging &   │ │ SQLite Cache  │ │ Media & Crypto│  │
│  │ Loader/Bridge │ │ Markdown      │ │ (rusqlite)    │ │ (SHA256/Wave) │  │
│  └───────┬───────┘ └───────────────┘ └───────────────┘ └───────────────┘  │
└──────────┼────────────────────────────────────────────────────────────────┘
           │ C ABI (dlopen / dlsym)
┌──────────▼────────────────────────────────────────────────────────────────┐
│                TDLib Native Library (libtdjson.so v1.8.65)                │
│                   Official Telegram MTProto 2.0 Servers                   │
└───────────────────────────────────────────────────────────────────────────┘
```

#### Модель данных и состояние
- **Состояние авторизации (`TdAuthState`)**: Переходы `WaitTdlibParameters` → `WaitPhoneNumber` / `WaitOtherDeviceConfirmation` (QR) → `WaitCode` → `WaitPassword` (2FA) → `Ready`.
- **Чаты и папки (`TelegramChatModel`)**: Идентификатор, тип (`private`, `basicGroup`, `supergroup`, `channel`, `bot`), последнее сообщение, счётчик непрочитанных, флаги `isPinned`, `isMuted`, `isVerified`, био/описание и список участников.
- **Сообщения (`TelegramMessageModel`)**: Поддержка текста с Rust-сущностями (`Bold`, `Code`, `Url`, `Mention`), цитируемых ответов, медиатипов (`PHOTO`, `VOICE`, `VIDEO_NOTE`, `DOCUMENT`), реакций с отметкой выбора текущим пользователем и статусов прочтения.
- **Кэш Rust SQLite (`RustGramDatabase`)**: Таблицы `chats`, `messages`, `contacts` с индексированным полнотекстовым поиском.

#### Маппинг интерактивных компонентов
- **iOS Bottom Bar (`Contacts`, `Calls`, `Chats`, `Settings`)**: Переключение корневых вкладок с сохранением состояния прокрутки и бейджем непрочитанных сообщений.
- **Свайп по сообщению / Долгое нажатие**: Горизонтальный жест обновляет `replyingToMessage` в экране чата; долгое нажатие открывает модальную панель реакций и действий, вызывающих `toggleReaction`, `pinMessage`, `editMessage`, `deleteMessage` в `TelegramRepository` → TDLib + Rust SQLite.
- **Кнопка микрофона / скрепки**: Проверка разрешения `RECORD_AUDIO`, старт записи `.m4a` через `MediaRecorder`, расчёт амплитуд в Rust (`VoiceWaveform`) и отправка в чат; выбор фото через `PickVisualMedia` с превью перед отправкой.
- **Глобальный поиск**: При вводе текста одновременно фильтрует локальный кэш чатов/сообщений через Rust JNI и отправляет `searchPublicChats` в TDLib.
- **Мастер создания группы/канала**: Выбор участников из контактов, ввод названия и описания, создание чата и мгновенный переход в открытую переписку.
