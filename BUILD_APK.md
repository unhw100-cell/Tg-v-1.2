# Как получить APK через GitHub Actions (без компьютера)

В проект добавлен workflow `.github/workflows/build-apk.yml`. Он собирает debug APK в облаке GitHub Actions.

1. Загрузите содержимое проекта в корень своего GitHub-репозитория. Важно сохранить папку `.github/workflows` и файл `build-apk.yml` внутри неё.
2. Откройте репозиторий на GitHub и перейдите во вкладку **Actions**.
3. Выберите workflow **Build RustGram APK**.
4. Нажмите **Run workflow** → **Run workflow**.
5. Дождитесь завершения сборки. Зелёная галочка означает, что задача завершилась успешно.
6. Откройте завершённый запуск и скачайте артефакт **RustGram-debug-apk**. Внутри будет APK для установки на Android.

Если сборка завершится ошибкой, откройте запуск в Actions, разверните красный шаг и сохраните последние строки лога — по ним можно определить точную причину.

Это debug-сборка для тестирования, не релизная подписанная версия для публикации в Google Play. Не публикуйте её как production-релиз.
